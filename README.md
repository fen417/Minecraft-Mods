# Модпаки Dawn of Larston

Настройки каждого модпака находятся в **[modpacks.json](modpacks.json)**. Версии больше не зашиты в лаунчер.

```json
{
  "id": "larston",
  "name": "Dawn of Larston",
  "minecraft_version": "1.21.1",
  "mod_loader": "neoforge",
  "mod_loader_version": "21.1.265",
  "mods_directory": "mods",
  "additional_files": "downloads/downloads.zip",
  "legacy_manifest": "mods-manifest.json"
}
```

- `minecraft_version`: точная версия Minecraft.
- `mod_loader`: `forge`, `neoforge`, `fabric`, `quilt` или `vanilla`.
- `mod_loader_version`: точная версия загрузчика. Для `vanilla` укажите пустую строку `""`.
- `id`: постоянный уникальный идентификатор латиницей, например `larston` или `my-pack`. Не меняйте его при обычном обновлении модов.
- `name`: название в списке лаунчера.
- `mods_directory`: папка с JAR-файлами этой сборки. Подпапки и кэши не публикуются как моды.
- `additional_files`: ZIP с настройками и ресурсами; можно удалить поле, если архив не нужен.
- `legacy_manifest`: необязательное имя старого манифеста. Для нового пакета поле можно пропустить.

Чтобы добавить модпак, добавьте объект в массив `modpacks`, создайте его папку с модами и укажите версии. Поддерживаются произвольные папки: изменения любого `.jar` или `.zip` запускают генерацию. Для опционального мода оставьте префикс `opt` в имени JAR. Обязательные моды в лаунчере отключать нельзя.

После изменения файлов в `main` workflow **Generate modpack manifests** проверяет конфиг и публикует `modpacks-manifest.json` в релизе `mods-latest`. Дождитесь зелёного результата Actions, затем перезапустите лаунчер или нажмите **Обновить** возле списка модпаков. Лаунчер читает опубликованный каталог, поэтому изменение настроек не требует пересборки приложения. Workflow можно запустить вручную через `workflow_dispatch`.

Каталог содержит версии, контрольные суммы SHA-256 и ссылки на файлы конкретного коммита. Это исключает смешивание старого списка модов с новыми файлами ветки `main`. Старые MD5-манифесты тоже генерируются, но старые лаунчеры не умеют переключать версии игры: нужен лаунчер 1.1.0 или новее.

Начальные настройки: `mods` — Minecraft 1.21.1 / NeoForge 21.1.265; `mods1` — Minecraft 1.21.11 / Fabric 0.20.1. Эти загрузчики доступны в официальных каталогах и соответствуют требованиям версий загрузчика в текущих модах. Совместимость модов между собой требует проверки в игре.

## Архивы настроек

Лаунчер устанавливает только каталоги конфигурации и ресурсов (`config`, `defaultconfigs`, `configureddefaults`, `resourcepacks`, `shaderpacks`, `datapacks`, `kubejs`, `scripts`, `schematics` и другие перечисленные в `ModpackInstaller.cs`) и файлы `options.txt`, `optionsof.txt`, `optionsshaders.txt`, `servers.dat`. Сохранения, логи и кэши из ZIP игнорируются. Не помещайте миры игроков в архивы дистрибутива.

При изменении ZIP обновляются только файлы, которые игрок не менял. Пользовательские настройки сохраняются. Файлы, ранее установленные лаунчером, удаляются при исчезновении из ZIP только если их содержимое осталось неизменным.

## Проверки локально

Требуется Node.js 22 или новее, внешних npm-зависимостей нет:

```powershell
node --test scripts/generate-manifests.test.mjs
$env:GITHUB_REPOSITORY = 'fen417/Minecraft-Mods'
$env:GITHUB_SHA = git rev-parse HEAD
node scripts/generate-manifests.mjs
```

Результат записывается в `generated/`. Для публикации используйте workflow после коммита: файлы по URL должны существовать в указанном SHA. Репозиторий модов и release assets должны быть доступны игрокам без приватного GitHub-токена.
